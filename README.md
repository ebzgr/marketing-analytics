# marketing-analytics

Web slides for **AIDAMS · Marketing Analytics** (ESSEC).

## View the slides

Open Session 1 in the browser:

**https://ebzgr.github.io/marketing-analytics/session-01/**

Or clone this repo and open `session-01/index.html` locally (a local server is recommended for some browsers).

## Contents

| Path | Description |
|------|-------------|
| `session-01/` | Session 1 deck (Reveal.js) |
| `css/` | Shared theme |
| `js/` | Shared scripts |
| `assets/` | Shared assets (e.g. ESSEC logo) |

Arrow keys / space to navigate. Theme toggle is at the bottom-left.
